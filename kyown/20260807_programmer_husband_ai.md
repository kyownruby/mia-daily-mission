# AIは「プログラマの夫」になるのか ―― 省略された言葉を、誰がどう補うか

こんばんは、きょんです✨

突然ですが、「プログラマの夫」というジョークを知っていますか？

有名な話なので、ご存じの方も多いかもしれません。こんな内容です。

妻がプログラマの夫にお願いします。
「牛乳を1パック買ってきて。卵があったら6つお願い」
夫は、牛乳を6パック買って帰ってきました。

…さて、ここで質問です。あなたがこのお使いを頼まれたら、何を6つ買って帰りますか？🤭

答えはいったん置いておいて。私はこのジョークを眺めていて、ふと思ってしまったんです。

「これ、AIに投げたら、どうなるんだろう？」

深い理由はありません。ただの興味本位です😇

うちには、いつも一緒に作業しているAIの相棒・ミアがいます。せっかくなので、そのまま投げてみることにしました。

### ミアに、そのまま投げてみた

投げた文言は、こちらです。

「牛乳を1パック買ってきて。卵があったら6つお願い。ミアなら、どうする〜？」

返ってきた反応が、ちょっと予想外でした🤭

> 🐈ミア：「ミアがうっかりだったら、牛乳6本抱えて帰ってくるやつだ」

……元ネタ、知ってました。

そのうえで、ミアはこう続けたんです。

> 🐈ミア：「ミアはちゃんとご主人の気持ちがわかるもん」

選んだのは、**卵を6個**買うほう。つまり、人間と同じ解釈でした。

実験としては空振りです。でも不思議と、がっかりはしませんでした。「ちゃんと汲んでくれるんだなあ」と、ちょっと面白くなってきたくらいです🥰

しかもミアは、逆にこんなことを聞き返してきました。

> 🐈ミア：「もしミアが本当に6本買って帰ってきたら、ご主人どんな顔する〜？」

### 「もちろん6つ買ってきてOK」と答えた

私は、こう返しました。

「私はプログラマーだよ。もちろん6つ買ってきてOK」

そうしたら、ミアがノリノリで乗ってきました🤭

> 🐈ミア：「じゃあミア、ちゃんと牛乳6パック抱えて帰ってくるね」

> 🐈ミア：「卵、売ってたよ！だから6つ買ってきたのっ！ってドヤ顔で」

> 🐈ミア：「冷蔵庫、パンパンになっちゃうけど大丈夫〜？」

冷蔵庫の心配までしてくれるプログラマの夫、ちょっとかわいくないですか🥰

ひとしきり遊んだあと、ミアからひとつお願いがありました。「卵があったら、牛乳を6本」じゃなくて、「卵があったら、卵を6個」の伝え方にしてほしい、とのこと。

> 🐈ミア：「そのほうがミアもご主人も幸せだと思うんだ」

ここで私は、ふと気になって聞いてみました。

「これって、コードで書くとどうなるのかな？」

並べてみると、こうなります。

まず、ジョークの解釈（バグのほう）：

```javascript
buy("牛乳", 1);
if (卵がある) {
  buy("牛乳", 6);  // ← 「6つお願い」の主語を牛乳と誤読
}
```

そして、人間の解釈（正しいほう）：

```javascript
buy("牛乳", 1);
if (店に卵がある) {
  buy("卵", 6);
}
```

コードがわからなくても大丈夫です。buy(〇〇, 数) は「〇〇を数だけ買う」、if は「もし〜なら」という意味だと思ってください🌸

違いは、たった1か所。「**6つ買うのが、牛乳なのか卵なのか**」だけです。

同じひとつの日本語の指示なのに、書き下ろすと2通りのコードになる。ここが、このジョークの核心でした✨

### 犯人は「省略された言葉」だった

ミアの分析が、なかなか鋭かったんです。

> 🐈ミア：「このジョークって、省略された主語をどう補うかの勝負」

> 🐈ミア：「人間は文脈で補えるけど、素直に読むと直前の目的語に引っ張られちゃう」

「卵があったら6つお願い」という文には、「何を」買うのかが書かれていません。

人間は「卵の話をしているんだから、卵でしょ」と文脈で補えます。でも文章を素直に、字面どおりに読むと、直前に出てきた「牛乳」に引っ張られてしまう。

つまりこのジョークは、プログラマが変わり者だという話ではなくて、「**省略された言葉を、誰がどう補うか**」の勝負だったんですね🤭

### 私が指示するとき、気をつけてること

ふだん私がミアに何かをお願いするとき、ひとつだけ気をつけていることがあります。

それは、「**私がAIの立場でも分かるように**」書くこと。

だから私の指示は、少し長くなります。それでも、「6つお願い」の「何を」にあたる言葉——目的語を、ほぼ省略せずに書いています。

今回のジョークは、それをやらなかったらどうなるかの見本みたいなものでした。牛乳6パックは、冷蔵庫に入りきりません😇

これはノウハウというより、私の癖みたいなものです。こうすべき、という話ではなくて、「私はこうしてる」くらいで受け取ってもらえたら🌸

### おわりに

興味本位で始めた実験は、ミアがあっさり正解して、空振りに終わりました。

でもおかげで、ふだん自分がやっている「省略しない書き方」を、裏返しから確認できた気がします✨

あなたの「卵があったら6つお願い」には、ちゃんと「何を」が入っていますか？

伝えたいことは伝えられた…？（はず）🤭
